### Authentication
1. As a user, I want to sign up using Google.
2. As a user, I want to log in securely.
3. As a user, I want to view my profile.
### Skills
1. As a user, I want to select a skill.
2. As a free user, I should only have one active skill.
3. As a premium user, I can have multiple skills.
### Milestones
1. As a user, I want to see my next milestone.
2. As a user, I can mark a milestone complete.
3. As a user, I can postpone a milestone.
4. As a user, I cannot skip milestones entirely.
### Progress
1. As a user, I want to log study hours.
2. As a user, I want to maintain streaks.
3. As a user, I want to see my total hours studied.
### Pods
1. As a user, I can create a pod.
2. As a user, I can request to join a pod.
3. As a pod owner, I can accept/reject requests.
4. As a pod owner, I can remove inactive members.
5. A pod cannot exceed 7 members.
### Community
1. As a user, I can participate in the skill community.
2. As a user, I can join community channels.
3. As a user, I can send messages in pod chat.
4. As a user, I can send messages in community chat.
5. As a user, I can join voice channels to talk to fellow learners of the community.
6. As a user, I can join pod voice channels to talk to my pod members.
